Put your image files here, named to match what App.jsx expects:

  hero.jpg            -> shown in the hero section
  tile-trainer.jpg     -> shown in the large "Trainer-Led Series" tile
  tile-nutrition.jpg   -> shown in the "Nutrition" tile
  tile-community.jpg   -> shown in the "Community" tile

Get free images from unsplash.com or pexels.com, download them,
rename them to match the names above, and drop them in this folder.
No code changes needed after that -- just restart `npm start` if it's
running, or refresh the browser if it's already running.
